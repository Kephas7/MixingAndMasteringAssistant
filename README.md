# Mixing and Mastering Assistant

An interactive Streamlit application for analyzing audio, separating stems, recommending EQ and compression settings, and checking masters against streaming targets.

## Quick start

1. Create and activate a Python virtual environment.
2. Install dependencies with `pip install -r requirements.txt`.
3. Run `streamlit run app.py`.

Generated models belong in `models/`; evaluation output belongs in `results/`.
