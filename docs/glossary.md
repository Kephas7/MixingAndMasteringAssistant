# Glossary

- **Crest factor:** difference between peak and RMS levels.
- **dBTP:** decibels relative to estimated true peak.
- **LRA:** loudness range, describing macrodynamic variation.
- **LUFS:** loudness units relative to full scale.
- **RMS:** root mean square, a measure of average signal energy.
- **Stem:** an isolated musical source such as vocals or drums.
